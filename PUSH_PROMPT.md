## После пуша — забрать вручную

В git не попадёт ничего из этого:

| Что | Откуда взять |
|---|---|
| `.env` трёх конвейеров | из репозиториев на этой машине — они уже поправлены |
| SSH-ключ до `root@141.136.44.9` | `~/.ssh` |

`AGENTS.md` переносить не нужно — он лежит в репозитории маршрутки и уедет
вместе с ним.

Серверные `.env` тоже можно забрать, но они старее — пока без `API_KEY` и без
блока ElevenLabs:

```bash
scp root@141.136.44.9:/opt/ezhu-ponyatno/.env  ~/ezhu-ponyatno/.env
scp root@141.136.44.9:/opt/story-to-video/.env ~/story-to-video/.env
scp root@141.136.44.9:/opt/zad-pegasa/.env     ~/zad-pegasa/.env
```

Дальше — по `HANDOFF.md`.
