Политика конфиденциальности

Действует с 25 августа 2026

Marshrutka — панель управления для внутреннего конвейера подготовки и публикации видео (проекты «Ежу понятно», «Истории в видео», «Зад Пегаса»). Сервис принадлежит и управляется одним оператором для собственных YouTube-каналов, публичной регистрации пользователей нет.

Какие данные Google/YouTube мы запрашиваем

Приложение использует YouTube Data API v3 с разрешениями:

  • https://www.googleapis.com/auth/youtube.upload — загрузка готовых видео на канал
  • https://www.googleapis.com/auth/youtube — управление метаданными загруженных видео (название, описание, теги, статус видимости) и чтение списка каналов аккаунта для выбора нужного при первой авторизации

Эти разрешения запрашиваются только у самого оператора сервиса для его собственных каналов. Приложение не запрашивает доступ к данным сторонних пользователей YouTube и не работает с чужими аккаунтами.

Как данные используются

Полученный доступ используется исключительно для автоматической публикации видео, подготовленных конвейером, и обновления их метаданных. Видео перед публикацией собирается программно (обработка исходного материала, синтез речи, монтаж) без участия сторонних сервисов, не связанных с этим приложением.

Хранение и защита

OAuth-токены (client secret, refresh token) хранятся в зашифрованном на уровне файловой системы виде на сервере оператора, доступ к файлу ограничен правами доступа операционной системы (0600, только root). Токены не передаются и не логируются в открытом виде, не покидают сервер оператора ни в каком другом виде. Видеофайлы хранятся временно — на время обработки и до подтверждённой публикации, затем удаляются.

Передача третьим лицам

Данные, полученные через Google API, не продаются, не передаются рекламным сетям и не используются в целях, не связанных напрямую с публикацией видео на собственных каналах оператора.

Доступ к самой панели Marshrutka

Вход в панель защищён отдельным пин-кодом — это не связано с Google OAuth и не даёт доступа к каким-либо данным Google. Панель не хранит и не отображает секреты каналов (client secret, access/refresh token) — они доступны только серверному процессу публикации.

Отзыв доступа

Отозвать доступ приложения к аккаунту Google можно в любой момент на странице myaccount.google.com/permissions.
