# Marshrutka

Репозиторий в переходном состоянии. Прежняя маршрутка была системой управления
конвейерами: очередь, планировщик, реестр проектов, публикация, встроенный
агент. Управление переехало в Hermes, и от неё остаётся окно — дашборд, инбокс,
история, прогоны.

## Что где сейчас

| Папка | Что это | Статус |
|---|---|---|
| `marshrutka-ui/` | Новая маршрутка: 5 страниц, ни базы, ни секретов | Готова, вынести в корень |
| `hermes-pipelines/` | MCP-слой между Hermes и конвейерами + HTTP API | Готов, вынести в свой репозиторий |
| `CODER_PROMPT.md` · `HANDOFF.md` | Что делать дальше и в каком порядке | Читать первым |
| остальное в корне | Прежняя версия | Удалить, см. ниже |

## Целевая схема

```
браузер ──> marshrutka :8100 ──HTTP──> hermes-pipelines :8010 ──> :8000 :8001 :8002
            (отдельный сервер)          (сервер с конвейерами)      три конвейера
                                              ▲
                                       stdio/MCP │
                                          Hermes (крон раз в сутки)
```

Маршрутка ничего не решает и ничего не хранит: она читает то, что отдаёт API.
Снести её и поднять заново можно в любой момент, ничего не потеряв.

## Что удалить из корня

Всё это реализовывало функции, которых больше нет:

```
agent/            встроенный агент — его работу делает Hermes
templates/        страницы удалённых разделов
static/           кроме логотипов и фавиконок (перенесены в marshrutka-ui/static/)
ui.py             47 KB интерфейса старой системы
api.py            REST старой очереди
models.py registry.py runner.py scheduler.py storage.py remote_sync.py
youtube_adapter.py    перенесён в hermes-pipelines/pipelines_mcp/youtube.py
projects/ data/   реестр и состояние переехали в hermes-pipelines
main.py config.py заменены версиями из marshrutka-ui/
```

`data/publish_profiles.json` перед удалением прогнать через
`hermes-pipelines/scripts/migrate_profiles.py` — там OAuth-креды трёх каналов
и VK-токен, лежащий открытым текстом в поле `notes`.

`DOCS.md`, `AI_DOCS.md`, `PUBLISHING_ACCESS_GUIDE.md` описывают прежнюю версию.
Помечены баннером, оставлены как справка по удалённому коду.
